# WorldGen 0.5.0 — редактор мира для Windows

Первый настольный выпуск WorldGen на Tauri 2. Приложение генерирует физическую основу фэнтезийного мира, строит геологический атлас и позволяет править карту с предпросмотром, отменой и повтором.

## Возможности

- Воспроизводимая генерация по семени: сферическая сетка, тектоника, рельеф, четыре сезона, осадки, реки и природные области.
- Геологический атлас: породы, провинции и четыре подземных слоя до глубины 12 км.
- 32 вида сырья и 24 семейства месторождений, полиметаллические тела, малые проявления, фильтры и карта рудного потенциала.
- Региональное уточнение области 700 × 700 км.
- Редактор рельефа, осадков, потенциала и залежей; подписи, закрепления и локальная перегенерация ресурсов.
- Системные диалоги открытия и сохранения проектов, JSON, PNG и шаблонов правил.
- Полные версии мира в локальном хранилище приложения.

## Загрузка и запуск

Для Windows x64 подготовлены:

| Файл | Назначение |
| --- | --- |
| `WorldGen_0.5.0_windows-x64.zip` | Переносимая версия: распакуйте и откройте `WorldGen.exe`. |
| `WorldGen_0.5.0_x64-setup.exe` | Установщик NSIS с выбором русского или английского языка. |
| `SHA256SUMS.txt` | SHA-256 каждого файла загрузки. |

Для работы нужен Microsoft Edge WebView2 Runtime. Node.js и Rust нужны только разработчикам. Интерфейс приложения — на русском языке.

## Проверка

Прошли 58 JavaScript-тестов и 3 Rust-теста. В собранном приложении проверены генерация, карта потенциала, предпросмотр, применение, отмена/повтор и сохранение локальной версии. Проект сохранён через системный диалог и открыт обратно; PNG 1280 × 640 записан и проверен.

## Ограничения

Это предварительный выпуск. Физика и геология рассчитаны для согласованного миростроения и не откалиброваны для научного прогноза. Региональное уточнение наследует глобальные условия и не пересчитывает локальный климат и реки. Поселения, политика, магия, добыча и экономика пока не реализованы.

Локальные версии из браузерного WorldGen не переносятся автоматически: сохраните проект в JSON и откройте его в настольном приложении. Сборки для macOS и Linux не подготовлены. Установка и перенос на другую машину пока не проверены.
