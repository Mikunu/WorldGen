# WorldGen 0.5.0 — Windows x64

1. Распакуйте архив целиком в любую папку.
2. Откройте `WorldGen.exe`.
3. Дождитесь появления карты и создавайте свой мир.

Установка WorldGen не нужна. Для работы нужен Microsoft Edge WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/ . Если приложение не запускается из-за отсутствия WebView2, установите Evergreen Runtime для x64 с сайта Microsoft или используйте установщик WorldGen из того же выпуска. Node.js, Rust и исходники для запуска не нужны.

При запуске WorldGen создаёт мир с семенем `Ember-001`. Выберите слой карты, нажмите на участок для просмотра данных или измените параметры и нажмите «Создать мир».

В редакторе можно менять рельеф, осадки и рудный потенциал, добавлять и редактировать залежи, закреплять области и подписывать карту. Правки сначала показываются в предпросмотре; после применения доступны отмена и повтор.

«Сохранить проект» записывает весь мир, правки и параметры просмотра в JSON. «Открыть» загружает сохранённый проект. Кнопки JSON и PNG под параметрами генерации сохраняют мир и текущую карту через системные диалоги.

Именованные версии хранятся в профиле приложения на текущем компьютере. Для переноса и резервного копирования используйте файл проекта.

Это ранняя процедурная модель для миростроения. Климат, геология и ресурсы приближённые; числа не являются научным прогнозом. Поселения, политика, магия, добыча и экономика пока не реализованы.

Контрольные суммы файлов выпуска находятся в `SHA256SUMS.txt` рядом с файлами загрузки. Исходный код и полная документация поставляются отдельно от этого архива.
