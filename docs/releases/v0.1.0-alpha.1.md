# WorldGen 0.1.0-alpha.1 — правила генерации и циркуляция океана

Ранняя альфа для Windows x64. Обозначение версии теперь явно отражает стадию разработки; переход к 1.0 требует отдельного решения о готовности продукта. Предыдущие опубликованные теги сохраняются.

После опубликованной 0.5.0 добавлены:

- Отдельное окно правил: 514 полей в 14 разделах, импорт и экспорт JSON, ожидающие правила для следующей генерации.
- 37 ограниченных формульных точек для рельефа, климата, океана, геологии, почв, опасностей и ресурсов. Проверка выражений, справочник переменных и отдельный предпросмотр.
- Масштаб карты 1–8×, панорамирование, независимые чекбоксы слоёв и настройка их прозрачности.
- Поверхностные течения, SST и влияние переноса тепла на климат.
- Двухслойная циркуляция океана: поверхностная и глубинная температура, солёность, потенциальная плотность, глубинные течения и вертикальный обмен. Девять независимых океанских слоёв, четыре сезона и точные значения в инспекторе.

Пресноводное воздействие использует предварительные осадки, испарение и речной приток. Перенос тепла и соли замыкается внутри бассейнов. Исправлена численная ошибка восстановления скорости в узких морских участках. Легенды глубинных течений и вертикального обмена показывают малые значения.

[Шаблоны для импорта](../../examples/), [правила](../implementation/generation-rules.md), [формулы](../implementation/generation-formulas.md), [океанская модель](../implementation/ocean-thermodynamics.md), [совместимость проектов](../ocean-projects.md).

Старые проекты сохраняют ранее рассчитанную карту и климат. Новые поля появляются после пересчёта с включёнными правилами; повреждённые и частично записанные поля отклоняются. Проверенный подробный проект 384 × 192 с плотностью ресурсов ×4 занимает 144,63 МиБ; лимит проекта — 200 МиБ.

Это процедурная модель для миростроения. Морской лёд, непрерывная стратификация и многовековая эволюция океана не рассчитываются. Поселения, политика, магия, добыча и экономика пока не реализованы.

Сборка Windows x64 предназначена для предварительного выпуска GitHub. ZIP содержит `WorldGen.exe` и краткую инструкцию; отдельно доступны установщик NSIS и `SHA256SUMS.txt`. Для запуска нужен WebView2 Runtime.

Проверки: 146 тестов ядра, 152 JavaScript-теста настольной копии и 3 Rust-теста прошли. Проверка номеров включает запуск сценария из отдельного клона без соседнего браузерного проекта. Все 69 общих файлов синхронизированы. В интерфейсе проверены версия 0.1.0-alpha.1, генерация и независимые океанские слои; журнал браузера без ошибок. Строковые ресурсы EXE и установщика содержат полный номер альфы. Подробные сценарии океана, импорта и формул зафиксированы в [результатах этапа 0.9](v0.9.0.md).
