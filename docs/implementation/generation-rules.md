# Правила генерации

«Правила генерации» задают численные параметры следующего нового мира: тектоники, климата, поверхностной циркуляции океана, биомов, эрозии, регионального уточнения, геологии, почв, опасностей, рудных поясов и ресурсов. Они не исполняют код и не добавляют произвольные типы пород, минералов или месторождений: доступны только безопасные диапазоны уже существующей модели.

В редакторе правила хранятся отдельно от рассчитанной карты. Изменение правил создаёт **ожидающие правила**: текущий рельеф, климат, атлас и авторские правки не переосмысляются. Создайте новый мир, чтобы применить их. В проекте сохраняются оба состояния: активные правила мира и ожидающие правила редактора.

Кнопка «Правила генерации» открывает отдельное окно. Вкладка «Новый мир» содержит общие правила и импорт JSON; вкладка «Ресурсы текущей карты» — шаблоны локальной перегенерации. Закрытие окна сохраняет черновик. При запуске правки окно закрывается, чтобы показать предпросмотр на карте.

## Файл правил

Импорт и экспорт используют UTF-8 JSON. Полный экспорт имеет формат:

```json
{
  "format": "worldgen-generation-rules",
  "version": 2,
  "rules": {
    "climate": { "equatorialTemperature": 32 },
    "resources": { "placer": { "enabled": false } }
  }
}
```

Можно импортировать и только объект `rules`, без обёртки. Любое неуказанное поле получает обычное значение. Неизвестные поля, нечисловые значения, числа вне диапазона и несовместимые пары минимум/максимум отклоняются. Размер файла ограничен 100 КБ.

Разделы файла: `world`, `tectonics`, `climate`, `biomes`, `erosion`, `region`, `ocean`, `geology`, `soils`, `hazards`, `mineralization`, `resources`, `rocks`, `depositModels`. Идентификаторы пород и семейств месторождений являются встроенными и не меняются. Раздел `ocean` ограничивает ветровой дрейф, поворот Кориолиса, торможение у берега, перенос тепла, температуру поверхности и связь с воздухом. У `depositModels` можно отключить семейство, изменить частоту, порог среды, диапазоны глубины, массы и содержания; например, `coal-basin` и `gold-vein`.

Пример тёплого мира с редким золотом и более частыми угольными бассейнами:

```json
{
  "climate": { "equatorialTemperature": 34, "latitudeCooling": 38 },
  "depositModels": {
    "coal-basin": { "frequency": 2.5 },
    "gold-vein": { "frequency": 0.35, "threshold": 0.4 }
  }
}
```

Параметры `world` задают начальные значения планеты. Обычные поля создания мира — семя, разрешение и явно заданные параметры — имеют приоритет над `rules.world`.

## CLI

Команда `scripts/generate.mjs` поддерживает параметр `--rules <путь-к-json>`. Он читает тот же формат, что и импорт редактора. При использовании правила сохраняются в JSON мира, поэтому повторная генерация с тем же семенем, параметрами и файлом правил воспроизводима.

```powershell
node scripts/generate.mjs --rules examples/generation-rules-example.json --seed custom-world --width 192
```

Правила содержат 514 редактируемых полей в 14 разделах. Проверяются также суммарные содержания и масштабы глубины/массы, согласованность диапазонов и объём расчёта. Существующие шаблоны локальной перегенерации ресурсов (`worldgen-rules`) продолжают использоваться в своём разделе.

В 0.9 раздел «Океан: поверхность и глубина» содержит 31 настройку. Термохалинную циркуляцию можно отключить отдельно от ветровой поверхности. Солёность зависит от осадков, испарения и речного притока; температура и солёность задают потенциальную плотность и опрокидывание. Глубокий слой существует только ниже `deepMinimumDepthM`, который должен превышать `surfaceLayerDepthM`. [Описание двухслойной модели](ocean-thermodynamics.md) и [готовый файл для импорта](../../examples/thermohaline-rules-example.json).

Численные результаты остаются процедурной моделью для миростроения, а не геологическим или климатическим прогнозом.
