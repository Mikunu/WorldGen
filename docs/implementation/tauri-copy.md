# Настольная копия WorldGen 0.5 · 3 октября 2026

Самостоятельное приложение, оболочка Tauri 2.11.5, CLI 2.12.1, Windows x64. HTML, карта и расчёты в Web Worker перенесены из исходного прототипа. Для файловых операций добавлен `src/desktop.js` и две Rust-команды с системными диалогами. В готовом EXE встроены только файлы интерфейса и расчётов.

## Подтверждённые проверки

- ZIP выпуска распакован в отдельную папку и запущен оттуда с новым профилем WebView2. Проверены генерация 18 432 ячеек, карта потенциала, предпросмотр, применение, отмена/повтор и сохранение локальной версии; ошибок консоли нет. В папке для запуска нужны только EXE и инструкция, Node-сервер и исходники не используются. На тестовой машине WebView2 установлен.
- 58 JavaScript-тестов прошли: 56 исходных и 2 проверки мостика Tauri (UTF-8 JSON, PNG, отмена диалога и ошибки).
- 3 Rust-теста прошли: проверка форматов, допустимое имя файла, запись с заменой, чтение и ограничения размера/кодировки.
- Сборка переносимого Windows EXE и установщика NSIS завершилась успешно. EXE: 8 765 952 байта; установщик: 2 001 902 байта.
- Запущен release EXE, интерфейс загрузился по `http://tauri.localhost/` без локального Node-сервера. Мир Ember-001, 192 × 96: 18 432 ячейки, 363 месторождения, 1 841 малое проявление; генерация около 2,21 с.
- Через работающий WebView проверены отдельный Worker потенциала 384 × 192, Worker редактора, предпросмотр, применение, отмена и повтор изменения правил, сохранение полной версии в IndexedDB. Ошибок в журнале WebView во время проверки нет.
- Через реальные системные диалоги сохранён проект `output/tauri-saved-project.json` (19 686 049 байт), затем открыт обратно в редакторе. Дополнительно проверен парсер проекта: seed, 18 432 ячейки, ревизия 1, сохранённые правила и слой.
- Через реальный системный диалог экспортирована карта `output/tauri-export-map.png`: 1280 × 640, 938 999 байт; сигнатура PNG и размер проверены по записанному файлу.
- 34 исходных файла ядра, тестов, документации, рендера, Worker, HTML/CSS и сервера совпали побайтно с исходным проектом.

Автоматическая проверка работающего release-приложения: `node scripts/desktop-smoke.mjs`; нужен тестовый запуск с `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=9437 --remote-debugging-address=127.0.0.1"`. Скрипт сохраняет `output/tauri-smoke-report.json` и `output/tauri-preview.png`. Обычный `start.cmd` отладочный порт не включает. Проверка меняет правила текущего мира и сохраняет тестовую версию; запускайте её в тестовом экземпляре.

## Особенности среды проверки

Cargo не смог подключиться к crates.io из ограниченной среды из-за ошибки Schannel `SEC_E_NO_CREDENTIALS`; для сборки использован существующий локальный кэш и `CARGO_NET_OFFLINE=true`. Это параметр текущей проверки, а не обязательная настройка проекта.

Первый запуск WebView2 и распаковка NSIS потребовали доступа к локальным папкам AppData за пределами рабочей папки. Операции выполнены с разрешением среды. Установщик собран; установка на систему не выполнялась. Перенос на другой компьютер не проверялся.

При повторной упаковке CLI предупредил о повторном добавлении метки типа пакета в уже обработанный EXE. Обновления приложения через updater не настроены; установщик был успешно создан. Для обычной новой сборки используйте `build.cmd`.
