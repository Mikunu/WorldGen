# Версии WorldGen

Текущая версия — **0.1.0-alpha.1**. WorldGen находится в ранней альфе: физические модели, форматы проектов и инструменты редактирования продолжают развиваться.

Номер имеет вид `0.MINOR.PATCH-alpha.N`. Ветка **0.1.x** предназначена для развития и проверки нынешнего генератора и редактора. **0.2.0** обозначит следующий согласованный этап продукта. MINOR меняется по решению об этапе, PATCH — для очередного обновления опубликованной альфы, N — для повторных кандидатов сборки одной версии до публикации. Порядок номеров соответствует [SemVer](https://semver.org/lang/ru/).

Каждая публичная альфа создаётся как GitHub **pre-release** с неизменяемым тегом `v0.MINOR.PATCH-alpha.N`. Уже опубликованные теги, включая исторический `v0.5.0`, сохраняются. Исправленный выпуск получает новый номер и тег. Новая схема начинается с 0.1 по оценке зрелости продукта; номера 0.5–0.9 в исторической документации отражают прежние этапы реализации. Сброс номера приложения не меняет версию формата проекта и не откатывает реализованные возможности.

Версия 1.0 не назначается автоматически по числу функций или выпусков. Перед ней требуется отдельное решение: согласованный объём продукта, проверенная совместимость проектов и миграций, надёжные сохранение и восстановление, пройденные проверки основных сценариев в собранном приложении и понятные ограничения модели.

## Смена номера

В папке настольного проекта:

```powershell
node scripts/set-version.mjs --set 0.1.1-alpha.1
node scripts/set-version.mjs --check
```

Сценарий обновляет package.json, Cargo.toml, запись WorldGen в Cargo.lock, конфигурацию Tauri, номер в интерфейсе и имя EXE в start.cmd. Если рядом находится исходный браузерный проект WorldGen, его package.json и интерфейс также обновляются. Следом нужно обновить описание выпуска и Windows quickstart, выполнить проверки и пересобрать приложение.

В проверенной сборке Windows строковые ProductVersion и FileVersion содержат полный SemVer. Числовое представление ресурса имеет вид `0.MINOR.PATCH.0`. Поэтому для следующего публичного установщика повышайте PATCH, например `0.1.1-alpha.1`: один только суффикс alpha.N не гарантирует правильного сравнения установщиков Windows. Полный SemVer используется в именах файлов, описании выпуска и Git-теге. Установщик разрешает переход с исторической 0.5.0 на новую схему 0.1.x; идентификатор приложения и формат сохранений остаются прежними.

Упаковка сверяет метаданные и хеши исходного результата сборки, переносимого и версионного EXE. Выпуски 0.x без `-alpha.N` отклоняются; подготовка будущей стабильной версии требует явного ключа `-AllowStable`.
